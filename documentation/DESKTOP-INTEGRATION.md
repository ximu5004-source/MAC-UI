# 桌面整理、办公通知与窗口动画集成

本次修改在现有 MAC UI 架构内实现，沿用原来的桌面工具条、磨砂整理盒、通知卡片和设置组件。

## 使用入口

- 桌面工具条「整理」开启分类布局；原生桌面右键菜单的「MAC UI 桌面整理 → 新建整理盒」设置名称、扩展名规则、映射文件夹和显示器。
  图标可跨盒拖动，右键打开 Windows Shell 文件菜单。布局在当前用户的 widget 数据目录保存。
- 办公通知沿用通知中心和托盘入口。系统 Toast、托盘 NIF_INFO 和可访问性提示窗文字合并展示，
  相同消息去重；点击卡片激活对应客户端。
- 右键 Dock 空白背景 →「Dock 窗口动画」可选「神奇效果」或「Windows 默认」，选择立即保存，并可跳转原有 Dock 设置页。默认神奇效果；
  Windows 动画偏好、节能策略、截图保护及性能预算会优先决定是否使用原生动画。

## 参考机制与实现

DeskGo 的静态分析确认了整理盒与项目归属、多屏网格占位、默认分类、排序与保存校验机制。
桌面核心已拆成独立领域模型、应用引擎与 Svelte 呈现层，使用自己的 JSON 数据结构，保留原项目的磨砂 UI。
全新配置保持 r1 原版名称视图；「按腾讯方式整理」显式把文件夹放入「我的文件夹」、普通文件放入「我的文件」，`.lnk` 和系统项留在桌面。
旧布局保留，可通过布局备份恢复。

单击、多选只显示紧凑圆角选中框，不自动弹出文件操作栏。空白处拖拽支持桌面跨盒框选和盒内框选，
Ctrl 切换命中项目、Shift 增选、Esc 取消。初始化和隐藏原生图标都成功后才接管桌面空白，失败时恢复 Explorer。

桌面项目来自 User/Public Desktop 的真实文件及当前可见的 Shell 系统项。图标使用 Windows 原生提取结果；
64 像素图标采用 80×108 像素圆角选择区域，水平、垂直间距分别可调。整理盒分配本身不移动源文件；
重命名、复制、剪切、粘贴、Delete 与 Shift+Delete 调用 Windows Shell，使用真实目录项、系统确认与错误交互。
文件右键菜单由 `IContextMenu` 提供，保留第三方 Shell 扩展；跨父目录多选使用真实 ResultsFolder 代理 PIDL。
空白右键调用实际 Explorer 桌面视图的原生背景菜单，在一个 MAC UI 子菜单中放置整理功能。
目录映射只列出直接子项，其文件操作作用于原文件。原生 OLE 拖放可跨应用，复制/移动使用 Shell 返回的实际结果路径。

MyDockFinder 样本确认了系统 `UserNotificationListener` 与微信／钉钉 MSAA 提示窗两条通路。
项目保留已有 WinRT Toast 管理器，并加入独立 STA 的提示窗读取器，检查所属进程、窗口类型、
可见性和 MSAA 角色。企业微信、飞书使用系统通路或严格的通用 Alert 规则，实际正文可用性由客户端决定。
通知内容只取自系统公开接口；不会读取聊天数据库或进程消息内存。

Genie 使用独立实现的 26×26 网格与余弦收拢阶段，向实际 Dock 图标方向变形，恢复时反向展开。
内存缓存按窗口、进程、类名和原始位置核验。无法安全执行时直接完成原生窗口操作。
3840×2160 窗口参与动画，按帧耗时自适应内部绘制分辨率；自有 4K 窗口已完成截图、最小化和恢复探针。
当前接入 Dock 发起的最小化与恢复，包括携带目标坐标的多窗口预览恢复；标题栏和系统快捷键仍走 Windows。

隔离 UI 验收可在前端构建后运行 `node scripts/qa/desktop-integration-server.mjs`，
打开 `http://127.0.0.1:3592/`。该页面载入真实生产组件，原生命令全部由虚构数据桥拦截；
布局仅保存在这个测试页的浏览器存储，不操作真实桌面或客户端。图标同样为测试占位图。

原始逆向证据保存在 `D:\逆向\deskgo-analysis` 和 `D:\逆向\mydockfinder-analysis`；
本次修改前的源码备份在 `D:\逆向\integration-baseline`。未修改原安装包，也未将目标二进制、
贴图或反编译函数作为项目依赖。原生混合 DPI、多显示器热插拔及各办公客户端版本仍需实际桌面验收。
腾讯云服务与完整产品功能尚未复刻；最近/常用视图使用本管理器的打开记录。
当前 Wry 拖入目标的悬停指针可能显示「复制」，实际文件操作仍按目标、Ctrl/Shift 与卷位置选择；Alt 拖放创建快捷方式暂不支持。
Windows Shell 无法保持身份的尾点/尾空格名称会拒绝操作，避免路径规范化后误操作同名的其他目录项。
