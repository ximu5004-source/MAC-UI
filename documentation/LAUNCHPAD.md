## 使用

- 使用原来的应用菜单入口打开；默认全屏，右下角可切换窗口模式。
- 顶部搜索可找到文件夹里的应用。点击或回车启动；保留 `apps:`、`files:` 和 `web:` 搜索范围。
- 底部分页点、左右按钮、滚轮、`Ctrl + ← / →`、`PageUp / PageDown` 可翻页。
- 应用叠放可建文件夹；应用拖到已有文件夹可加入。支持新建空文件夹、文件夹内改名、内部排序。右键提供移入/移出文件夹、跨页移动和解散文件夹。
- `Esc` 先关闭文件夹或清除搜索，再返回启动台，最后关闭窗口。

## 开始菜单导入与安全边界

首次打开时，在保留旧收藏布局的基础上导入当前用户和公共开始菜单的快捷方式，以及已注册的应用列表。以后点击“导入开始菜单”合并新项目；导入不会覆盖已有顺序、改名和分组，也不会重复添加相同应用身份。

使用 Windows Known Folder API 获取 Programs 目录。按快捷方式所在的相对目录生成启动台文件夹；深层目录显示为“父文件夹 / 子文件夹”，不创建嵌套文件夹。空物理目录不会导入。相同应用身份（UMID）或快捷方式路径会去重；不同用途的帮助、卸载、网页快捷方式保留。

这里的文件夹是启动台的虚拟分组。改名、移动、解散只修改启动台布局，**不会移动、重命名或删除 Windows 开始菜单中的真实文件**。不是对 Windows 11 开始菜单固定项目分组的双向同步。

背景只读取当前 Windows 静态壁纸并做模糊展示，不启用、修改或接管壁纸管理模块。动态壁纸不作实时镜像。
