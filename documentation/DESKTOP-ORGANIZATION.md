# 桌面整理

桌面管理保留 MAC UI 的磨砂窗口和 Svelte 5 控件。文件图标直接显示 Windows 提取的原生图标，
不套玻璃底或应用图标蒙版。Windows 桌面右键菜单中的「MAC UI 桌面整理 → 新建整理盒」可创建可移动、缩放、折叠的空盒。
工具栏控件、重置布局语义和首次名称视图以已核验的 `MAC-UI-3.0.1-product-polish-20261030-r1` 为基准。

## 实际文件与选择

默认显示用户 Desktop 和 Public Desktop 的实际文件。单击选择，Ctrl 单击增减选择，Shift 单击选择同盒范围；只显示紧凑圆角选中框，不弹出操作栏。
在桌面或整理盒空白处按住左键拖拽即可框选。普通框选替换选择，Ctrl 框选切换命中项目，Shift 框选增选；从盒内开始只选择该盒的可见项目。拖拽时显示圆角选框，松开后只保留图标选中框，Esc 取消本次框选。图标拖放、盒标题拖动、缩放和文字编辑不会触发框选。
图标右键与 Shift+F10 打开 Windows Shell 原生菜单，包含系统已注册的第三方扩展。
Ctrl+C/X/V 执行复制、剪切、粘贴；映射盒中的粘贴目标为该盒已保存的目录，普通盒和桌面背景粘贴到用户 Desktop。Delete 请求回收，Shift+Delete 请求永久删除，
由 Windows 提供确认、权限及冲突交互。Alt+Enter 打开属性，F2 或原生菜单「重命名」进入内联名称编辑。
原生操作完成、失败或取消后都会重新读取文件，以反映 Windows 已完成的部分操作；刷新异常不会覆盖原始操作异常。

文件夹映射显示选定绝对目录的直接子项。映射中的原生菜单、重命名及删除操作作用于原文件。
映射不复制文件，也不递归列出目录。路径不可用时显示错误；启动、刷新、修改映射及原生操作后重新读取。

## 分类、整理盒与排序

菜单「按腾讯方式整理」显式启用腾讯样本确认的两个默认盒：文件夹进入「我的文件夹」（ID101对应），
其他普通文件进入「我的文件」（ID102对应），`.lnk` 快捷方式和 Shell 系统项留在无盒桌面区。
`.exe`、`.url` 属于普通文件。前者默认按修改时间排序，后者默认按时间分组。
全新配置保留原版名称视图；旧配置作为兼容输入保留，显式切换保留已有自定义盒、规则、手动归属、位置和尺寸；
上一代配置可通过恢复上次保存回退。

- 拖动桌面项目到其他普通盒，调整显示归属。这是显示归属调整，文件仍在原位置。
  同一盒内为视觉排序。内部 Desktop 项目无修饰键拖到普通盒只改变归属；映射盒、外来文件、Ctrl 复制及 Shift 移动使用 Windows Shell 实际文件操作。
  复制/移动后只给 Windows 返回的真实目标路径分配归属，包含冲突改名结果。取消不伪造新文件。
  桌面内拖动保持原版指针排序和边缘连续滚动；原生命中测试确认指针进入其他应用窗口后才进入 OLE，可拖到资源管理器或其他应用。外来拖入按原生落点转换到对应盒。
  Alt 拖放创建快捷方式尚不支持，会明确提示并保持文件不变。Ctrl+上/下仍可调整视觉顺序。
- 扩展名规则接受 `pdf, docx, txt`。手动归属优先，多条规则匹配时先创建的盒优先。
  自定义扩展名分类是额外规则；默认文件夹/普通文件分流按已确认的腾讯行为。
- 一个盒可同时展示其规则匹配的桌面项目和链接目录的直接子项；重复路径只显示一次。
- 删除整理盒仅删除盒配置、规则与手动归属，不删除任何文件。
- 背景菜单可全局按名称、类型、修改日期、大小排序；盒设置可独立选择排序方式。
  名称使用自然数字顺序；类型优先使用 Windows 本地化类型名称；修改日期和大小从大到小。
  「按时间分组」使用样本中的「最近一周」「一周前」两组标题，按修改时间的滚动 UTC 7×24 小时归组；满 7 天进入「一周前」。样本对最近组头有额外 1 秒存在性容差，边界时可能出现空组头；组头和独立行数参与布局。
- 「一键整理」重新计算空位并将手动顺序恢复为名称顺序，保留规则、归属和用户调整的盒尺寸。
  「锁定布局」锁定盒位置、尺寸和一键布局，文件操作、排序及折叠仍可用。
- 背景菜单可显示「最近打开」「我的常用」。这里的记录来自本桌面管理器的打开操作，
  不是 Windows 全局最近文档。常用按已有固定标记、打开次数和时间排序。
  记录只展示当前桌面或映射目录中仍可用的项目，每个视图最多 100 项，不夺走普通盒的归属。

## 图标、间距与多屏

64 像素图标使用 80×108 像素圆角选择单元，名称默认两行，选中或聚焦时按原版展开。桌面原生菜单的整理子菜单中「图标间距」分别调整水平、垂直间距，
范围 0–64 像素。间距同时影响普通桌面网格、盒内列数、滚动高度、拖放定位和自动空位布局，保存后可恢复。
已有自定义盒位置和尺寸保持不变。

盒设置可指定显示器，各屏独立保存位置和尺寸。屏幕断开时临时回落主屏，保存的原屏布局仍保留。
默认盒先保留已有位置，再寻找无重叠空位；放不下时在对应屏幕画布中上下滚动，手动放置允许重叠。
布局使用单一原生桌面窗口的物理坐标，包含负坐标屏幕；混合 DPI 的数学转换已有测试，原生交互仍需现场验收。

## 保存与恢复

布局、规则、排序、图标尺寸/间距和本地打开记录保存在 widget 的 `desktop-shell.json`。
schema 3 保留旧分类布局并区分默认整理策略。串行写入前保留上一份已验证配置为 `desktop-shell.backup.json`，原子替换并回读验证；失败时尝试恢复上一份。
编辑面板保存失败会保留草稿。损坏文件先另存为 `desktop-shell.corrupt-时间.json`；无法保留时暂停写入。

背景菜单「布局备份」可创建手动快照，或恢复手动快照/上一份配置。恢复前仍保留当前配置供再次恢复。
备份包含配置，不复制或回滚真实文件；删除文件不能通过布局恢复找回。

## 实现和验证边界

`domain/` 管理纯数据、选择、排序、活动记录及多屏占位，`application/DesktopOrganizer.ts` 管理操作与持久化，
Svelte 组件负责呈现、焦点、指针、键盘和原生命令适配。

桌面空白右键使用实际 Explorer `IShellView::GetItemObject(SVGIO_BACKGROUND)` 提供的 `IContextMenu`，
原生 `HMENU` 保留查看、排序、刷新、新建、显示设置、个性化和第三方扩展；MAC UI 仅追加一个整理子菜单。
不通过网页重画 Windows 主菜单，也不向全局注册自有 Shell 扩展。菜单命令使用原生 ID 调用，
原生视图变化通过 `IFolderView2` 回读；取消菜单和无关命令不能重置原有布局。
显式关闭 Windows 自动排列后，普通桌面图标保留现有坐标并可自由拖动；对齐图标与整理框的网格吸附独立。
原生排序会重新排列松散图标；重新启用自动排列恢复网格。原生重命名保留松散图标的坐标。

安装版 DeskGo 4.3.1832.127 的取证确认：桌面 group1 和整理盒均有 MiniSkin 自绘网格/列表承载路径，
同时使用真实 Shell 菜单、图标、OLE 数据对象和 Explorer 桌面视图协作。出现 `SysListView32` 或
`IFolderView2` 不能证明其可见条目直接复用 Explorer 控件。原始函数与运行窗口证据见
`D:\逆向\deskgo-analysis\findings-icon-carrier.json`；尚未确认的 Explorer 图标遮挡机制不作为实现依据。

本项目独立实现已观察到的盒/条目分离、多屏占位、排序和保存验证机制，不分发 DeskGo 程序、图片或反编译代码。
尚未实现腾讯云服务、其他扩展分类规则、任意目录实时监听、递归映射、定时快照、Windows 全局最近文档，
也没有把腾讯未确认的普通盒与映射盒拖放行为假定为物理移动。OLE 拖放采用 Windows 文件语义，并未声称逐分支复刻腾讯未恢复的拖放矩阵。初始化及隐藏原生图标都成功后，widget 接管各显示器桌面空白以支持框选和拖入；初始化或区域更新失败时恢复 Explorer 图标并撤销空白交互区。
当前 Wry 的 WebView2 拖入提示固定使用复制效果；实际操作仍由落点、修饰键和 Windows 卷规则决定，光标提示不一定准确反映移动或仅调整归属。
原生混合 DPI 拖放、显示器热插拔、Explorer 共存及真实桌面重启恢复仍需 Windows 交互验收。
