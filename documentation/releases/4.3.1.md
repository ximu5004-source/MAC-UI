# MAC UI 4.3.1

发布日期：2026-11-23。安装包适用平台：Windows 11 x64。

## 桌面操作

桌面空白处使用 Windows 原生右键菜单，保留查看、排序、刷新、新建及系统和第三方应用提供的菜单项，并附加 MAC UI
桌面子菜单。 菜单使用标准参数向 Windows 请求命令。

整理盒按鼠标位置移动，松手后保留当前位置。靠近相邻整理盒边缘 12 DIP 时吸附，按住 Shift 可临时关闭吸附。
新建整理盒选择邻近空位。跨显示器拖动使用目标显示器的可用区域和缩放比例，折叠的整理盒保留展开高度。

桌面管理继续使用 C#、WPF 和 Windows Shell，玻璃透明度、磨砂强度及桌面选项集中在 MAC UI 设置中。

## 安装与配置

运行 `MAC-UI-4.3.1-x64-Setup.exe`。主程序、服务、命令行、窗口钩子与桌面程序一同部署。
安装需要管理员授权，界面与桌面进程以普通用户权限运行。

配置位于 `%APPDATA%\com.jona.mac-ui`。桌面布局保存在 `data\macui-desktop-shell`，操作日志位于同目录的
`native-desktop.log`，包含出错接口、错误码和 Windows 版本。

运行依赖 Windows 自带的 .NET Framework 4.8 或后续版本。 安装包附带 Microsoft Visual C++ 与 WebView2
的离线安装程序，按需安装运行库；已有较新 Visual C++ 运行库时保留现有版本。 WebView2 最低版本为
110，缺少运行库或版本低于要求时使用包内程序安装或升级。 安装包附带资源完整性签名，并保留上游版权、AGPL-3.0-or-later
许可证和第三方署名。

回退时正常退出 MAC UI，重新安装保留的 4.3.0 安装包，并恢复升级前备份的配置。
