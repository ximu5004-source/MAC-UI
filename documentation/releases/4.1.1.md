# MAC UI 4.1.1

- MAC UI 采用纯蓝底白色单线 M 标志；设置的主按钮、开关、选中项和键盘焦点统一为蓝色。
- 设置采用 26 px 窗口圆角、24 px 功能卡片、32 px 顶部工具条和透明窗口四角。首页可配置桌面、Dock、顶部栏、启动台与消息弹窗，点击卡片标题进入详细设置。开关沿用设置窗口的保存和撤销操作。
- 微信和企业微信的未读数量增加时可以再次弹出提醒。Windows 勿扰状态仍然生效，音量或亮度等数据源读取失败时，通知浮层仍可工作。
- Windows 或客户端公开通知正文时，卡片可显示正文。仅收到未读信号时，弹窗与通知中心显示「您有一条来自“微信”的新消息。」或对应的应用名称。

- 修正设置内容区只占窗口 65% 高度的问题，使可见底边和原生窗口底边对齐。

本地源码标签为 `v4.1.1`，上一版为 `v4.1.0`。各版本的安装包、源码压缩包与 SHA-256 校验文件保存在各自的版本目录。
