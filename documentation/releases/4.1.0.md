# MAC UI 4.1.0

- 鼠标停在有运行窗口的 Dock 应用上约 260 毫秒即显示缩略图，可以移入选择窗口或关闭窗口。单击一个窗口的应用仍可切换或最小化，多个窗口也可通过键盘打开预览。
- 打开设置，窗口顶端可直接选择「原版玻璃」或「增强对比」。增强模式保留透明材质，并加深轮廓、强化文字及图标边缘。没有其他待保存的设置时立即生效，有待保存的改动时点击「保存」统一应用。设置窗口采用视频工作台的窄导航和胶囊工具条。
- 微信通知支持从可访问的浮窗中分别读取发送者和正文。使用 Windows 原生测试窗口验证了分开显示的两段文字。实机测试微信 4.2.0.53 时，Windows 通知中心没有收到这条测试消息，MAC UI 也没有从浮窗读到正文，最终显示「微信新消息」。

## 本地版本规则

本地开发分支为 `macui/main`。用 `v主版本.次版本.修订号` 标签标记发布源码。兼容的新功能递增次版本，修复递增修订号，不兼容变更递增主版本。已发布标签和安装包永久保留，新版使用新目录。

打包时核对 package.json、Cargo 自有程序包、桌面 SDK 及锁文件的版本。安装包核验通过后，将 Git 标签、源码压缩包和安装包 SHA-256 对应到同一版本。可用 `git worktree add --detach ../MAC-UI-4.0.0 v4.0.0` 在独立目录检出上一版。
