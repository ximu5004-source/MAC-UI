# MAC UI 3.0.1 desktop integration r2

The desktop file icon hover no longer shows path or operation hints. Its native
Shell menu is prepared on a persistent STA and retained in a bounded cache for
recent selections, with clipboard, metadata, saved roots, modifier and environment
invalidation. Menus retain Shell extensions. Native fade is omitted; foreground,
keyboard and outside-click cancellation are explicit.

Notification dispatch is installed before optional WinRT event registrations.
Toast snapshots reconcile every 500 ms, even if event registration fails. A
windowless MTA collector supplements MSAA with read-only UIA notification regions
for recognized client-owned transient windows. Real WeChat 4.1.15.56 and WeCom
incoming-message acceptance remains pending; no mock notification proves client
compatibility.

Genie now observes the Windows minimize/restore events as well as the Dock and
native caption input. It primes a bounded memory-only frame cache off the UI and
hook threads. A service lease temporarily suppresses native minimize/restore
animation without writing the user profile, saves its actual original value,
and restores it on release or exact app-process exit. Custom playback requires
the service's acknowledgement. Selecting Genie is an explicit local motion
choice; OS reduced-motion signals do not erase measured Dock targets. Other
interface motion policies are unchanged.

The observed restore path parks a window in a visible iconic state during
playback and preserves its normal/maximized placement. It does not leave another
application hidden for the animation duration. There is no cross-process CBT
pre-interception in this revision: an observed restore can expose the real
window briefly before parking it. Protected, unavailable, stale and unsupported
captures preserve a reachable native window. Universal application coverage has
not been established.

Validation includes 187 passing main-binary Rust tests, explicit transparent
self-owned transition/interrupt probes, and a 3840×2160 capture and 55-frame
minimize/restore probe. Service custodian probes restored both original on/off
values after an owned child process exited. Frontend and binding type checks
passed. Menu request-to-Windows-popup-event samples were 25/26 ms when prepared;
an unprepared 279 ms sample remains over the 180 ms target. These are event
callback timings, not compositor first paint. Final package validation records
are delivered alongside the installer; real-client and all-application acceptance
must not be inferred from these automated checks.
