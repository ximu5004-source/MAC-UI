# MAC UI 3.0.1

[English](#english) · [简体中文](#简体中文)

## 简体中文

MAC UI 是由 JONA 维护、基于 [Seelen UI](https://github.com/eythaann/Seelen-UI) 二次开发的 Windows 桌面定制项目。保留上游作者与贡献者署名，遵循仓库中的 [LICENSE](https://github.com/ximu5004-source/MAC-UI/blob/v3.0.1/LICENSE) 和 [NOTICE](https://github.com/ximu5004-source/MAC-UI/blob/v3.0.1/NOTICE.md)。这是独立的衍生版本，不是 Apple 产品或 Seelen UI 官方发行版。

### 本次更新

- 启动台快捷键分组增加明确的启用开关，快捷键编辑支持单独的 Win 键。
- 修复初次读取和文件更新时的设置同步，以及禁用后重新启用快捷键时的键盘捕获。
- 按请求分别处理快捷键录入完成、取消和关闭，避免旧请求影响新录入。
- 保留已验收的玻璃界面、桌面整理、Dock 调节和应用网格启动台。
- 正式安装包在编译时排除 nightly 专用调试符号。

### 安装和限制

下载 `MAC-UI-3.0.1-x64-Setup.exe`，保存工作、退出旧版后运行安装器。已有配置不主动重写；单按 Win 打开自制启动台需要先启用启动台及相关快捷键。Win 组合键保留原生行为。

此安装器用于 Windows x64，没有 Windows Authenticode 代码签名，可能显示“未知发布者”。JONA 是作者与发布者信息，不代表受信任证书。内部资源完整性签名不等于 Windows 代码签名。

**Genie 吸入式最小化动画未启用，本次不提供该功能。** 本项目没有安装或修改 Windhawk，也不直接替换 Windows 系统文件。当前通过手动安装包更新。

## English

MAC UI is an independent Windows desktop customization project maintained by JONA and derived from [Seelen UI](https://github.com/eythaann/Seelen-UI). Upstream author and contributor attribution is retained. See [LICENSE](https://github.com/ximu5004-source/MAC-UI/blob/v3.0.1/LICENSE) and [NOTICE](https://github.com/ximu5004-source/MAC-UI/blob/v3.0.1/NOTICE.md). This is neither an Apple product nor an official Seelen UI release.

### Changes

- Add an explicit enable switch to the Launchpad shortcut group and support standalone Win in the shortcut editor.
- Fix initial and file-based settings synchronization and keyboard capture after disabling and re-enabling shortcuts.
- Isolate shortcut recording completion, cancellation and dialog closure by request identity.
- Retain the accepted glass interface, desktop organization, adjustable Dock and application-grid Launchpad.
- Exclude nightly-only debug symbols from the stable installer at compile time.

### Installation and limitations

Download `MAC-UI-3.0.1-x64-Setup.exe`, save your work, exit older instances and run the installer. Existing preferences are not proactively replaced. Enable the custom Launchpad and its shortcuts to use standalone Win; native Win-key combinations remain available.

This Windows x64 installer is not Authenticode-signed and may show an unknown-publisher warning. JONA identifies the author and publisher, not a trusted signing certificate. Internal resource integrity signatures are separate from Windows code signing.

**Genie minimization is disabled and is not delivered in this release.** MAC UI does not install or modify Windhawk or directly replace Windows system files. Updates currently use manual installers.
