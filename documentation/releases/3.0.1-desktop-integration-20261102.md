# MAC UI 桌面与窗口动画修正

2026-11-02。构建标识：MAC-UI-3.0.1-desktop-integration-20261102-r1。安装包名称与 SHA-256 见发行目录中的校验清单。

## 本次改动

- 桌面空白处与文件项目使用 Windows Shell 原生右键菜单；修正菜单失焦关闭和前台宿主的处理，避免菜单等待影响后续拖动。
- 整理框、其他整理框与散放图标允许重叠，移动、缩放时不再强制推开；保留原有圆角界面，菜单中的整理入口统一为“整理”。
- 桌面接管区域排除实际可见顶部栏区域，避免原生桌面窗口覆盖透明顶部栏下方。
- 移除桌面上的黑色文件操作等待条和红色内部错误条；用户取消文件操作按取消处理，不再误报为操作失败。Windows 原生确认对话框继续保留。
- Genie 动画支持 Dock 操作及标准原生标题栏最小化按钮，沿实际 Dock 图标位置收拢；恢复动画使用此前最小化保存的有效内存快照。可从“Dock 空白处右键 → Dock 窗口动画”切换神奇效果与 Windows 默认效果。
- 保留 4K 窗口的自适应渲染路径。动画结束、取消或出错时，先清空截图合成表面，再隐藏并销毁临时窗口，处理 Dock 附近截图残留的收尾路径。
- 控制中心底部齿轮改为直接打开 Windows 系统设置。

## 验证与覆盖范围

- 桌面测试 94 项、Genie 测试 20 项、文件取消处理测试 2 项、Dock 坐标测试 8 项、SDK 测试 105 项通过；类型与 Svelte 检查通过。
- 自有 4K 测试窗完成原生最小化与恢复，播放 55 帧；隐藏临时窗口的清理测试通过。测试实例确认标题栏监听已加载，4 个运行窗口的 Dock 目标均注册成功。
- Win+D、其他键盘或系统入口，以及不能返回标准原生最小化命中的自绘标题栏按钮，保留 Windows 默认行为。跨屏、受保护内容、捕获失败或超时、系统关闭动画等不满足条件的情况会回退系统效果。
- 第三方应用的实际标题栏点击、Dock 残留色、桌面白条及真实拖放等视觉与交互回归尚未完成，不能将上述自有窗口和自动检查视为这些场景已经验收。

本次不声明与腾讯桌面整理或 MyDockFinder 的完整功能、技术栈或实现方式一致，也不声明办公软件通知已完成全部客户端验收。
