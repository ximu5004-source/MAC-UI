# MAC UI 4.3.0

发布日期：2026-11-23。适用平台：Windows x64。

## 桌面管理

桌面管理采用 C#、.NET Framework 4.8、WPF 和 Windows Shell。顶部栏、Dock、启动台与设置继续由 MAC UI 主程序提供。

- 文件支持拖放、复制、移动、重命名、回收站和 Windows 文件菜单。拖动时显示跟随指针的图像。
- 整理盒支持空盒创建、手动分组、映射文件夹、解散、折叠、缩放和边缘吸附。
- 框选覆盖图标区域及最后一行下方的空白区域。
- 整理盒、控制条和菜单采用玻璃材质；透明度与磨砂强度可在设置中调整。
- 滚动条覆盖在内容右侧，操作结束后自动隐藏。
- 桌面窗口保持在普通应用窗口下方，辅助窗口不显示在任务栏和 Alt+Tab 中。

## 设置与运行

桌面设置集中在 MAC UI
的桌面分类中，包含玻璃材质、图标大小、间距、吸附、网格与布局锁定。设置窗口的三个控制按钮使用居中的矢量图标。

桌面进程以普通用户权限运行。文件操作使用 Windows 原生接口处理权限和冲突。正常退出等待文件操作结束并恢复 Explorer
图标；独立恢复进程负责异常退出后的恢复。

## 安装与配置

运行 `MAC-UI-4.3.0-x64-Setup.exe`。Windows
权限提示由用户确认。主程序、服务、命令行、窗口钩子和桌面程序随安装包一同部署。

配置位于 `%APPDATA%\com.jona.mac-ui`。桌面布局保存在其中的 `data\macui-desktop-shell`
目录。首次读取旧布局时保留迁移副本，原文件继续使用现有格式。

升级前备份位于 `E:\换皮\backups\MAC-UI-before-release-4.3.0-20261123`。回退时先正常退出 MAC UI，安装保留的 4.2.0
安装包，再恢复相应版本的用户配置。

安装包附带资源完整性签名；Windows Authenticode 状态以发布目录中的 `release.json`
为准。项目保留上游版权、AGPL-3.0-or-later 许可证和第三方署名。
