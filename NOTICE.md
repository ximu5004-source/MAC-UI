MAC UI is an independent Windows customization project, not an Apple product or an official Seelen release. macOS-inspired styling uses original interface code, Windows system fonts and an original MAC UI mark.

Author/publisher metadata is not a Windows Authenticode digital signature. No certificate or trusted-signature status is claimed.

The public product name is MAC UI and the Windows installer launches `mac-ui.exe`. Internal IPC, helper executable, resource and app-data identifiers are retained for compatibility with existing installations and layouts; development builds can still use the legacy executable name. Seelen accounts and its resource marketplace remain upstream services, explicitly identified as such.

This custom build uses manual updates. Upstream application update installation is disabled to avoid replacing MAC UI customizations with the original application. A future MAC UI updater requires its own release endpoint and signing key.
